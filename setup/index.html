1LinkTrip setup, one step at a time

Best on a computer. Do one step, text bbbot, then do the next. You never need to read or change the code: tap Copy, paste where it says, click the button it names.
Step 1 of 8 · about 2 minutes

Update the AI import

Lets guests upload booking screenshots and PDFs, and lets the AI work from 1linktrip.com.
  1. Open supabase.com/dashboard and click your project.
  2. Left menu → Edge Functions → click ai-import → the Code tab.
  3. Click inside the code, select all of it (Cmd+A on a Mac, Ctrl+A on Windows), then paste (Cmd+V / Ctrl+V) so the new code replaces the old.
  4. Click Deploy (bottom right). Wait until it says it’s deployed.
Then text bbbot “step 1 done”.
Step 2 of 8 · about 1 minute

Database setup, part 2

Saves each guest’s trip to their account so it follows them to any phone or computer.
  1. In your Supabase project, left menu → SQL Editor.
  2. Click + at the top left → Create a new snippet (or use the empty box if one is already open).
  3. Paste into the big box, then click Run (bottom right).
  4. If a box pops up saying Potential issue detected, click Run this query. That’s expected: it only replaces old settings, no data is deleted.
Worked if the results area at the bottom says Success. No rows returned.
Then text bbbot “step 2 done”.
Step 3 of 8 · about 1 minute

Database setup, part 3

Turns on guest messages, guest groups, and updates sent to chosen groups.
  1. Supabase → SQL Editor → + → Create a new snippet.
  2. Paste into the big box, then click Run.
  3. If Potential issue detected pops up, click Run this query.
Worked if it says Success. No rows returned.
Then text bbbot “step 3 done”.
Step 4 of 8 · about 2 minutes

Let sign-in work on 1linktrip.com

  1. Supabase → left menu → Authentication → URL Configuration.
  2. Site URL: replace what’s there with this, then click Save changes:
Site URLhttps://1linktrip.com
  1. Under Redirect URLs click Add URL, paste the first line below, click Save URLs. Do the same for the second line.
Redirect 1https://1linktrip.com/**
Redirect 2https://www.1linktrip.com/**
Leave the bbbot0209.github.io lines that are already in the list. They keep the old address working.
Then text bbbot “step 4 done”.
Step 5 of 8 · about 2 minutes

Let the maps work on 1linktrip.com

  1. Open Google Maps Platform → Keys & Credentials. Check 1LinkTrip is the project shown at the top.
  2. Click the key’s name (blue text), not the copy icon.
  3. Scroll to Website restrictions → Add → paste the first line → Done. Then Add again for the second line → Done.
Website 1https://1linktrip.com/*
Website 2https://www.1linktrip.com/*
  1. Keep the bbbot0209.github.io line that’s already there. Click Save at the bottom.
Google says it can take up to 5 minutes to start working.
Then text bbbot “step 5 done”.
Step 6 of 8 · about 3 minutes

Email sending: make a key and save it in Supabase

This lets 1LinkTrip email hosts and guests when someone sends them a message. The key is private: paste it only into Supabase, never into a text or email (not even to bbbot).
  1. Open resend.com/api-keys and sign in (or sign up, it’s free).
  2. Click Create API key. Name it:
Name1linktrip
  1. Permission: Sending access → click Add.
  2. Copy the key it shows (it starts with re_). Resend only shows it once, so keep that tab open until step 6 is finished.
  3. Supabase → left menu → Edge Functions → Secrets.
  4. Under Add or replace secrets, put this in Name:
NameRESEND_API_KEY
  1. In Value, paste your re_ key → click Save.
Then text bbbot “step 6 done” (just those words, no key).
Step 7 of 8 · about 2 minutes

Add the email function

  1. Supabase → Edge Functions → Deploy a new function → Via Editor.
  2. Click inside the sample code, select all (Cmd+A / Ctrl+A), paste (Cmd+V / Ctrl+V).
  3. At the bottom, set the function name to:
Namenotify
  1. Click Deploy function. Wait until it shows the function’s page.
Until 1linktrip.com is added in Resend (a later step bbbot will send), these emails only reach the email you signed up to Resend with. Messages always show inside 1LinkTrip either way.
Then text bbbot “step 7 done”.
Step 8 of 8 · optional, about 1 minute

Make www.onelinktrip.com go to 1linktrip.com

onelinktrip.com already forwards. The www. version doesn’t open anything yet.
  1. Namecheap → Domain List → onelinktrip.com → Manage → Advanced DNS.
  2. If there’s a row with Host www, delete it (trash icon).
  3. Add New Record → type URL Redirect Record. Host:
Hostwww
  1. Value:
Valuehttps://1linktrip.com
  1. In the dropdown next to it pick Permanent (301) → click the green check.
Then text bbbot “step 8 done”.
