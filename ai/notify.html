Message emails (optional)

Emails the host when a guest writes, the guest when the host replies, and guests when an update is posted for them. Messages already show in the app without this.

1. Database

  1. Run database setup, part 3 if you haven’t.

2. The function

  1. Tap Copy function → Supabase → Edge Functions → Deploy a new function → Via editor → name notify → paste → Deploy. Leave Verify JWT on.
  2. Edge Functions → Secrets → add RESEND_API_KEY (your Resend key, the same re_… one from sign-in emails works).

3. Your domain (when ready)

  1. Until a domain is verified in Resend, emails come from onboarding@resend.dev and Resend only delivers them to your own Resend email.
  2. After you add and verify a domain in Resend → Domains, add the secret NOTIFY_FROM = 1LinkTrip <hello@yourdomain.com>. No code change needed.
