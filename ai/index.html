AI import: Supabase Edge Function

  1. Tap Copy code below.
  2. Supabase Dashboard → Edge Functions → Deploy a new function → Via editor.
  3. Name it ai-import, replace the sample code with what you copied, and tap Deploy. Leave Verify JWT on.
  4. Edge Functions → Secrets → add ANTHROPIC_API_KEY with your Anthropic API key.

Eventpages shows “Start from a website” and AI email import automatically once the function answers. Only signed-in organizers can use it; each import is one Claude Haiku 5.5 call.
