Email forwarding (optional)

When this is set up, each organizer gets a private address like 3f9a…@trips.yourdomain.com. Forwarding a booking confirmation there adds it to their itinerary. Nothing here is on until you finish these steps; you need either your own domain on Cloudflare (free Email Routing) or a free Postmark account you own.

1. Database

  1. Run database setup, part 2 if you haven’t.

2. The function

  1. Tap Copy function → Supabase → Edge Functions → Deploy a new function → Via editor → name inbound-email → paste → Deploy.
  2. Open the function’s settings and turn Verify JWT off (email services can’t sign in; the function checks its own secret).
  3. Edge Functions → Secrets: ANTHROPIC_API_KEY (already set for AI import) and INBOUND_SECRET = a long random string.

3a. If you use Postmark

  1. Postmark → Servers → your server → Default Inbound Stream → Settings.
  2. Webhook URL: https://mljzoujystouqkmmoemn.supabase.co/functions/v1/inbound-email?secret=YOUR_INBOUND_SECRET
  3. Use your Postmark inbound address, or point a domain’s MX records at Postmark (their “inbound domain forwarding” guide).

3b. If you use Cloudflare Email Routing

  1. Cloudflare → Workers → Create → paste the worker below → add variables INBOUND_URL and INBOUND_SECRET.
  2. Your domain → Email → Email Routing → Routing rules → Catch-all → Send to a Worker → choose it.

4. Tell bbbot the domain

Once mail flows, send the inbound domain and PlanEZR will show each organizer their forwarding address in My pages.
