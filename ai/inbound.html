Forward a booking email → itinerary

People forward a confirmation (hotel, flight, tour…) to their own address, e.g. add-3f9a…@in.1linktrip.com, and it lands in their My trip. Mail arrives through Resend (receiving), on the subdomain in.1linktrip.com so 1linktrip.com's own email is untouched. About 15 minutes. Nothing shows in the app until the last step.

Already done

  2. Database: supabase/schema-inbound.sql is installed.

  1. Resend lists DNS records (DKIM, SPF). Add each in Namecheap → 1linktrip.com → Manage → Advanced DNS → Add New Record. In Namecheap's Host box, type the name Resend shows without .1linktrip.com on the end.
  2. Back in Resend, open the domain → turn on Receiving. It shows one more record, an MX. Add it in Namecheap (under Mail Settings → Custom MX if Namecheap asks):

Valuethe value Resend shows (e.g. receive.forge.rmta.net or inbound-smtp.us-east-1.amazonaws.com)
Priorityas shown in Resend (usually 10)
  1. In Resend tap I've added the record and wait until Receiving says Verified (minutes to an hour).

3. Resend: a key that can read received mail

Name1linktrip-inbound
  1. Permission Full access (the existing sending-only key can't read received emails) → Add → copy the key (re_…, shown once).

4. Supabase: three secrets

  1. Supabase → project → Edge Functions → Secrets → add each (name, then value):
NameRESEND_INBOUND_SECRET
Valuethe whsec_… signing secret from step 2
NameRESEND_INBOUND_API_KEY
Valuethe re_… key from step 3
NameINBOUND_DOMAIN
Valuein.1linktrip.com
INBOUND_DOMAIN switches the "Forward bookings" row on in the app, so add it last. Optional: NOTIFY_FROM = a sender on a domain verified in Resend (e.g. 1LinkTrip <hello@1linktrip.com>) sends a short "Added Hyatt Place Kyoto, May 10–22 to Japan Trip" email after each forward.

5. Try it

  1. Sign in on 1linktrip.com → open a trip → My trip → Forward bookings → Copy.
  2. Forward any hotel or flight confirmation to that address (or from the email you sign in with to trips@in.1linktrip.com).
  3. Within a minute it's in that trip's bookings (or under "forwarded bookings" in My pages when no trip's dates match).
