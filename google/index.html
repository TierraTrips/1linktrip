Get a Google API key

Best on a computer (about 10 minutes). Each step is one screen.
  1. Open Google Maps Platform. Tap: console.cloud.google.com/google/maps-apis/start
    Sign in with your Google account if asked.
  2. Make a project. At the top of the page, click the project picker (it may say "Select a project") → New project → name it:
    Eventpages
    → Create. Make sure "Eventpages" is now shown in the picker at the top.
  3. Add billing. Google will ask you to add a billing account (name, address, card). Follow its prompts and click Submit / Start. There's a monthly free allowance.
  4. Copy your key. After billing, Google shows a box titled something like "Your API key" with a long code starting with AIza. Copy it and keep this tab open.
    Don't see it? Left menu → Keys & Credentials → your key is listed there → Show key.
  5. Turn on the two services. Left menu → APIs & Services (or go to API list). Find each of these and make sure it says Enabled (click it → Enable if not):
    Places API (New)
    Maps JavaScript API
  6. Lock the key to our site. Open Maps Platform → Keys & Credentials (check "Eventpages" is selected at the top) → click the key's name (blue text, e.g. "Maps Platform API Key") — not the copy icon. That opens Edit API key; scroll down to Key restrictions:
    • Under Set an application restriction choose Websites → Add → paste:
    https://bbbot0209.github.io/*
    → Done.
    • Under API restrictions choose Restrict key → tick Places API (New) and Maps JavaScript API → OK.
    • Click Save. On a phone this page can be cramped — a computer is easier.
  7. Set a spending alert (recommended). Go to Budgets & alerts → Create budget → Next → amount:
    10
    → Finish. Google emails you if spend gets near $10/month.
  8. Text bbbot the key (the AIza… code from step 4). Once it's locked to our site it's safe to send.
