Google ratings & photos setup

About 10 minutes on a computer is easiest. This gives the app Google ratings, photos, hours and reviews for places.
  1. Open Google Cloud → New project. Name it Eventpages → Create.
  2. Turn on billing for that project: Billing → link a billing account (Google asks for a card; there's a monthly free allowance).
  3. Enable these two APIs (search each in API Library → Enable):
    Places API (New)
    Maps JavaScript API
  4. Credentials → Create credentials → API key. Then click the key to edit it:
    • Application restrictions → Websites → add these two:
    https://bbbot0209.github.io/*
    http://localhost/*
    • API restrictions → Restrict key → tick the two APIs from step 3 → Save.
  5. Safety cap: Budgets & alerts → Create budget → amount:
    10
    (emails you if spend nears $10/month).
  6. Text bbbot the API key. Because it only works from this site, it's safe to send — like the Supabase publishable key.
Never send anything labeled "service account" or a JSON key file — only the API key from step 4.
