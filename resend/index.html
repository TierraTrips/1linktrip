Sign-in emails via Resend

Removes Supabase's ~2 emails/hour limit on magic links.

1. Resend: make a key

  1. Open resend.com/api-keys → Create API key.
  2. Name it eventpages, permission Sending access → Add.
  3. Copy the key (starts with re_). It's shown once.

2. Supabase: turn on custom SMTP

  1. Supabase → your project → Authentication → Emails → SMTP Settings.
  2. Turn on Enable custom SMTP and fill in:
Sender emailonboarding@resend.dev
Sender namePlanEZR
Hostsmtp.resend.com
Port465
Usernameresend
Passwordyour re_… key from step 1
  1. Save.

3. Supabase: raise the limit

  1. Authentication → Rate Limits.
  2. Set Rate limit for sending emails to 100 per hour → Save.

Heads-up: domain

With the onboarding@resend.dev sender, Resend only delivers to the email on your Resend account — fine for testing yourself. To send sign-in links to anyone, add a domain you own in Resend → Domains (it gives you DNS records to add), then change Sender email to e.g. hello@yourdomain.com. Google sign-in works for everyone in the meantime.
